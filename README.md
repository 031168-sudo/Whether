# Whether

Android-приложение погоды: прогноз и история по координатам (геолокация устройства или ручной ввод широты и долготы), сравнение периодов разных лет по дням и месяцам.

Источник данных: [Open-Meteo](https://open-meteo.com) (forecast API и archive API).

## Стек

- Kotlin, Jetpack Compose, Material 3
- Retrofit + kotlinx.serialization (сетевой слой)
- Room (локальный кэш ответов)
- Vico (графики)

## Структура экранов

- **История**: выбранный период в виде таблицы и графика.
- **Сравнение**: от 2 до 4 периодов, наложенных по дням; метрики: минимальная, средняя и максимальная температура, влажность, ветер, осадки.
